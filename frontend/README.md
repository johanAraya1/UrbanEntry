UrbanEntry - Mobile (React Native / Expo)

Quick start

1. Install dependencies:

```bash
cd frontend
npm install
```

2. Start Expo:

```bash
npm start
# or
npx expo start
```

Notes
- This is a minimal scaffold created to migrate the frontend to React Native.
- The app uses the color palette defined in the web project (`tailwind.config.js`).
- To add the project logo: place the logo image at `frontend/assets/logo.png`. Edit `frontend/App.js` to render the image in the header instead of the text placeholder.
